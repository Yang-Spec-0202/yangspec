# 0001 静态 Hugo + Cloudflare Pages

- 状态：已采纳
- 日期：2026-11-01（补记；决定早于本次记录）
- 相关：[../architecture.md](../architecture.md)、[../ops/runbook.md](../ops/runbook.md)

## 背景

个人站以文字为主，页面数量少；不需要账号、数据库、服务端渲染。改版前是工具站，维护成本已经偏高，改版后要求长期低成本：无运行时依赖、无安全补丁负担、发布流程短。

## 决定

用 Hugo 0.167.0 extended 生成静态文件，托管在 Cloudflare Pages；`main` 分支即生产，PR 生成分支预览。

## 后果

- 没有服务端、数据库和运行时日志；访问数据只能依赖 Cloudflare 边缘层。
- 发布 = 合并 PR + 托管平台构建；回滚 = 平台部署回滚，二者都不需要登录服务器。
- 质量门槛只能靠构建期检查与实验室检查（`scripts/check.sh`、`scripts/preview-check.sh`），没有线上探针兜底。
- 所有动态能力（搜索、评论、表单）都要额外服务，而它们与 `/privacy/` 的数据流承诺冲突，因此默认不做。
- 托管平台和 Hugo 版本的配置不在仓库里，升级需要手动同步文档。
