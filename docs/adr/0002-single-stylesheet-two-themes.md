# 0002 单一站点样式表 + CSS 变量双主题

- 状态：已采纳
- 日期：2026-11-01（补记；决定早于本次记录）
- 相关：[../architecture.md](../architecture.md)、`CONSTRAINTS.md` 第 3 节

## 背景

PaperMod 自带的排版与改版后的视觉方向差异较大，需要覆盖；同时站点必须支持深浅两套主题。如果每个组件写两份颜色，深色模式一定会漏，且新增页面会不断复制样式。

## 决定

- `assets/css/extended/personal.css` 是唯一的站点样式入口，与主题样式一起由 Hugo 打包。
- 颜色、间距、字体全部走 `:root` 自定义属性；深色主题只覆盖同名变量。
- 主题切换只改 `<html data-theme>`，偏好存 `localStorage` 的 `pref-theme`。

## 后果

- 新增组件只要用变量，就自动拥有深浅两套配色；漏用变量会立刻在深色模式下暴露。
- 不引入 CSS 框架、预处理器或按组件拆分的样式文件；改样式只需看一个文件。
- 首屏 CSS 有体积上限（`CONSTRAINTS.md` 第 1、5 节），样式增长要克制，不能靠“多写点覆盖”解决。
- 主题自带的样式仍会参与打包；覆盖时尽量提高选择器语义，而不是加 `!important`（例外需注释原因）。
